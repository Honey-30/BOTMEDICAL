## 🔐 Authentication Notes

### Regular GitHub Account:
- Username: Your GitHub username
- Password: Your GitHub password

### 2FA Enabled Account:
- Username: Your GitHub username  
- Password: **Personal Access Token** (not your regular password)

### Create Personal Access Token:
1. Go to: https://github.com/settings/tokens
2. Click "Generate new token (classic)"
3. Select scopes: **repo**, **user**
4. Copy token and use as password

## 🚨 Troubleshooting

### Git Not Found:
- Download: https://git-scm.com/download/win
- Install with default settings
- Restart Command Prompt

### Authentication Failed:
- Use Personal Access Token for 2FA
- Check username/email are correct
- Verify repository exists

### Push Rejected:
- Repository might not exist
- Create at: https://github.com/new
- Or use: `git push -f origin main`
